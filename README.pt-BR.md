# TRUD

> Sistema ERP multi-tenant, open source, sob licença GPLv2.

## Sobre o projeto

O **TRUD** é um sistema ERP multi-tenant (uma única instância atende múltiplas empresas) inicialmente projetado para franquias de farmácias, mas com arquitetura pensada para ser adaptado a qualquer segmento.

Este é um projeto de código aberto. A ideia é que empresas possam utilizar o TRUD — ou adaptá-lo para outros fins, incluindo capacitação de estagiários — livremente, dentro dos termos da licença.

## ⚠️ Status do projeto

O TRUD está em **fase inicial de desenvolvimento**. Arquitetura, funcionalidades e decisões técnicas ainda estão sendo definidas e podem mudar significativamente sem aviso prévio.

**Não recomendamos o uso do TRUD em ambientes profissionais ou de produção neste momento.** Caso opte por utilizá-lo mesmo assim, o uso é por sua conta e risco — os desenvolvedores não se responsabilizam por eventuais problemas decorrentes disso.

## Tecnologias

- **Frontend:** React e Svelte
- **Backend:** Node.js + Express
- **ORM:** Prisma
- **Banco de dados:** ainda em debate/definição
- **Futuro:** está planejada uma versão mobile com migração/expansão para **React Native**
