# TRUD

> A multi-tenant, open source ERP system, licensed under GPLv2.

## About the project

**TRUD** is a multi-tenant ERP system (a single instance serves multiple companies), initially designed for pharmacy franchises but architected to be adapted to any business segment.

This is an open source project. The idea is that companies can use TRUD — or adapt it for other purposes, including training interns — freely, within the terms of the license.

## ⚠️ Project status

TRUD is in an **early stage of development**. Architecture, features, and technical decisions are still being defined and may change significantly without notice.

**We do not recommend using TRUD in professional or production environments at this time.** If you choose to use it anyway, you do so at your own risk — the developers are not responsible for any issues that may arise from it.

## Tech stack

- **Frontend:** React and Svelte
- **Backend:** Node.js + Express
- **ORM:** Prisma
- **Database:** still under debate/definition
- **Future:** a mobile version is planned, migrating/expanding to **React Native**

## How to contribute

Want to be part of TRUD? Open an **issue** telling us a bit about yourself:

- A brief introduction
- Your experience (technologies, previous projects, etc.)
- How you'd like to contribute

We'll review the issues and get back to you on whether there's room for you to join the project right now.

> Please keep your introduction **short and to the point**, so we can review it quickly without wasting your time or ours. 🙂
